AFUScale 1.2 蓝牙诊断版，用于收集 AFU-WL-TZ-A1 原始数据并对照秤面 / 阿福 App 体脂率。

- 全服务与特征发现、可读值读取、通知订阅及未知原始包日志。
- 持续连接、最终包与个人参数快照、人工测量标注。
- 持久化 JSONL、历史会话和完整日志 / 可读摘要导出。
- 默认采集模式不写健康；正常同步仅写体重与 BMI。

安装：下载本页 unsigned.ipa，在电脑上用 Sideloadly 重签安装到 iOS 17+ iPhone。它没有 Apple 分发签名，不能直接点击安装。诊断功能无需 HealthKit 权限。

使用：关闭阿福 App → 填个人资料 → 控制台新建会话 → 赤脚测量后等 15 秒 → 选最终包标注 → 停止 → 导出 JSONL 和 summary.txt。阿福 App 对照测量前需先停止采集释放蓝牙。

A/B 字段单位与厂商算法尚未确认；此版本用于采集证据，不能监听阿福 App，也不承诺更精准体脂率。编译与自动化测试通过不等同于真实秤验证。

详见仓库 README 与 docs/diagnostic-log-schema.md。
